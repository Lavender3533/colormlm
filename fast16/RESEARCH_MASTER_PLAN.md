# ColorLM Neural Alloy 科研总目标

首个正式候选保持在15GiB以内并可在8GB显存机器上部署；后续若能力证据成立，磁盘权重预算
可扩到50-70GiB。主要能力集中于编程、仓库理解、调试、工具调用和电脑控制。模型必须直接
包含融合后的神经权重，不用关键词判断、文本检索、多模型外部路由或云端API冒充模型能力。

## 已确认事实

- [x] RX 5700 XT 8GB、32GB RAM、i5-12400F 是固定部署目标。
- [x] ColorLM/Qwen3.6：40层、2048隐藏维度、256专家、top-8，733个张量完全对齐。
- [x] GLM-4.7：47层、2048隐藏维度、64专家、top-4，844个张量。
- [x] GLM 与 ColorLM 架构不同，但共享 2048 宽残差流。
- [x] 低秩路由差分需要很高秩，LoRA 不是完整合金的主要压缩方向。
- [x] q3_g64 全秩差分可保留约95.7%的路由差分方向。
- [x] 40层满秩路由 adapter 可推理，alpha=0 与基座固定输出一致。
- [x] 整块 GLM 共享专家替换可加载且速度正常，但语义输出崩坏。
- [x] GLM 共享专家随机输入输出能量约为 ColorLM 的5-28倍，方向余弦约0。
- [x] 每层保留480个 ColorLM 神经元、嫁接32个 GLM 神经元后短生成稳定。
- [x] Synaptic Graft 保持512共享专家宽度，不增加每 token 矩阵尺寸。
- [x] 当前嫁接模型为单一13.73GB GGUF，Vulkan短生成约17.6 token/s。
- [x] llama-server 已提供 Anthropic Messages、流式响应、token计数和工具调用协议。
- [x] q3_g64全量差分容器已生成：733张量、346.6亿逻辑参数、13.11GiB。
- [x] 40层q3路由差分已构建期融入单一v6 GGUF，不用LoRA或CPU自定义算子。
- [x] v6融合模型在RX 5700 XT上最短生成稳定，生成18.0 token/s，已接入Claude Code。
- [x] v10已在单图接入四颗真实Kimi K3 latent专家与隐藏态cosine/no-op软路由。
- [x] v11已让Coder E471与四颗K3专家在同一Vulkan token图中并行执行。
- [x] v12统一alloy plan已被正式启动器解析，五供体血统、13.146GiB有效体积、32K上下文、
  完整性校验和双侧链回滚契约均已验收。
