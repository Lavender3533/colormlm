# v23 高速能力蒸馏岛

## 目标

Fara整模只作离线教师。最终ColorLM不常驻27B密集文本干，而是增加一个按图像请求才激活的
视觉前端和一个小型动作残差头；纯文本解码路径保持v17，目标是零额外token延迟。

## 运行结构

```text
截图
  -> Fara视觉塔+merger（约0.864GiB，只做一次prefill）
  -> 5120→2048视觉桥（约20MiB F16）
  -> ColorLM v17文本主干
  -> no-op / CUA低秩动作残差头
  -> 原生248,320词表
```

Fara与ColorLM词表大小同为248,320，但必须先逐token比较原始bytes；只有完全相同的token行才能
直接做logit蒸馏。视觉桥用共享token嵌入作先验，再用同一截图/指令下的真实视觉token与深层状态
做矩形岭回归。禁止只凭“词表大小相同”或词嵌入几何写运行图。

## 教师采集

整模短门通过后，一次加载内完成：

1. 4个冻结首动作，确认本地量化保留目标能力；
2. 8–16个合成截图状态，每个只采正确首动作所需token；
3. 保存Fara最后一层隐藏态、top-32 teacher logits、动作JSON中的关键token位置；
4. 对同一图像/文字轨迹采ColorLM隐藏态；图像桥尚未存在时先采纯文本动作契约与teacher logits；
5. 按整条轨迹划分训练/外部留出，禁止相邻token随机拆分。

## 轻量运行参数

- 视觉桥：`5120×2048`，F16约20MiB；若低秩r256即可过门，则降到约3.5MiB。
- CUA动作残差头：优先rank64/128，输入ColorLM末端hidden，输出只覆盖预先枚举的动作、JSON结构、
  坐标数字和停止token候选行；目标常驻低于32MiB。
- no-op门：没有图像时不建立视觉或CUA节点；有图像时只在首动作关键token打开动作头。
- 不在每个token执行Fara层，不并行跑两个完整LM，不通过关键词选择能力。

## 训练目标

```text
L = KL(student_topK || teacher_topK)
  + 2 * CE(关键动作与参数token)
  + 0.25 * hidden_alignment
  + 0.1 * no_op_sparsity
```

训练样本来自Fara本地教师，不调用付费API。训练只更新视觉桥、低秩动作头和连续no-op门；v17主干、
Coder岛与安全旁路冻结。

## 晋级门

- Fara教师冻结首动作短门至少3/4，且两个关键点题必过；否则停止该供体。
- 蒸馏岛在未参与训练的4题上不少于教师通过数，且相对v17至少净增2题。
- 无图像`alpha=0`逐token等价v17；纯文本128-token速度变化不低于-2%。
- 有图像时首动作总时延以“视觉prefill一次+短decode”计，不允许用隐藏的第二LM进程作弊。

这一路只补电脑操作，不宣称通用推理已追平Claude/GPT。通用推理、知识和规划继续由后续独立供体
岛补齐，所有岛共享同一个no-op总线和冲突仲裁器。
