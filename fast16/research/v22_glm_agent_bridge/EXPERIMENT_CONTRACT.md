# v22 GLM Agent Bridge 独立验证契约

本轮目标不是把 GLM 强行做成运行版，而是用一批在 v21 方法和结果之后才创建的独立提示，
检验“GLM 深层状态可以稳定运输到 ColorLM”这一核心假设。

## 冻结规则

- `independent_agent_prompts.jsonl` 在采集或查看任何 v22 激活结果前冻结。
- 冻结文件为16条唯一提示、7149字节，SHA-256：
  `2438f52b8aca7b943769ff08b1f9d0a7bb60b8603f341272e7d6767e2d5a8362`。
- 旧 v21 的 12 条提示只允许用于拟合和选择正则；v22 的 16 条提示只允许作为外部留出集。
- 不允许根据 v22 结果删除提示、修改顺序、重新选择层位或扫描阈值。
- 入口固定为 ColorLM L35 `attn_residual`，供体固定为 GLM L42 `l_out`。
- 先评估已冻结的 v21 岭桥；随后只允许评估一个预先声明的候选：带偏置的锚定岭桥。

## 唯一新增候选

带偏置锚定岭桥在旧 v21 训练语料上拟合：

```text
donor = (base - mean_base) @ M + mean_donor
M = token_prior + anchored_ridge_correction
```

正则只在旧 v21 内层留出上选择。运行时将偏置折叠为一个 2048 维 F32 向量；不得用 v22
外部留出选择正则、尺度、奇异值截断或层位。

## 外部留出硬门

- 16/16 提示均成功配对，且总配对状态不少于 900。
- 相对共享 token 桥，余弦中位数提升至少 0.30。
- NRMSE 比率不高于 0.95。
- 至少 12/16 提示的余弦中位数获得正提升。
- 运行矩阵的奇异值截断固定为 `[0.25, 8.0]`，cycle RMSE 不高于 `5e-5`。

任一硬门失败即继续封存 GLM，不实现 C++ 连续岛。全部通过也只获得实现资格，不等同于
能力提升；之后仍需一个工具任务、一个规划任务和一次 `alpha=0` 旁路短门。
