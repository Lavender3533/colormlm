# ColorLM donor 侦察口径

**截止日期：** 2026-07-31（Asia/Shanghai）

## 证据等级

- **A（官方明确）**：模型组织的模型卡、配置、权重索引、许可证、技术报告或官方部署文档。
- **B（可复算推导）**：由官方 `config.json`张量形状、精度和官方 `model.safetensors.index.json`映射计算。
- **C（社区实现）**：非官方 GGUF/量化仓库，仅证明已有转换路径，不代表上游支持或质量保证。
- **U（未披露）**：官方没有给出，且不能从已公开配置可靠复算；禁止用传闻补齐。

HF `createdAt` 是仓库创建时间，只在官方未另行声明时当作发布日期。权重大小同时记录十进制 GB 与二进制 GiB；总参数优先用官方口径，但附带 MTP/DSpark/视觉编码器时另列 HF safetensors 实际计数。

## 基准与可比性

不同官方使用的 agent harness、推理预算、上下文长度和抽样参数不同。本侦察保留官方分数及测试条件，但只将同一表内、同一 harness 下的分数视为严格可比。内部基准会明确标记，不用于单独决定排名。

## ColorLM 接入基线

本地已验证的 Qwen3-Coder-Next donor 作为兼容基线：

- 48 层，隐藏维 `2048`，512 个路由专家，`top-10`，单专家中间维 `512`；
- tokenizer 词表 `151936`，embedding 与输出头不共享；
- ColorLM 现有代码已能对单专家、路由器、末端层和输出头做定点提取，并已验证 `2048×2048` 隐藏坐标桥；
- 同为 `2048/512` 的 Qwen3.5/Qwen3.6 MoE 供体可复用最多接口，但其 `248320` 词表与 Coder-Next 不同，输出头不能按 token id 直接替换；
- 隐藏维不是 `2048` 的供体必须训练入/出传输桥；该桥是能力验证的前置条件，不能由词嵌入几何高相似直接推导。

## 体积估算

- BF16 张量：`numel * 2` 字节。
- FP8 张量：`numel * 1` 字节，另加 scale 张量。
- FP4/MXFP4 张量：理论下限 `numel / 2` 字节，实际值需加 block scale、对齐和 safetensors header。
- Qwen `2048 -> 512 -> 2048` SwiGLU 单专家 BF16 的三矩阵为 `6,291,456` 字节；`256 x 2048` BF16 路由器为 `1,048,576` 字节。

## 决策标签

- **值得提取**：有明确互补能力，许可条件可接受，且存在可控的小张量/小切片实验路径。
- **只值得借鉴架构**：能力重要，但权重语义难隔离、坐标/词表代价太高，或许可条件不适合立即嵌入。
- **不值得投入**：对现有 donor 增量弱、官方证据不足，或工程/许可风险明显超过预期收益。

## 红线

本轮只读取模型卡、配置、权重索引和仓库文件清单；未请求任何 safetensors/GGUF 权重内容，未启停模型，未占用 GPU，未运行 CMake。
