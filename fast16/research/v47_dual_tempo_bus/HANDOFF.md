# v47 主线交接

## 一句话状态

`ColorLM-v38-Qwen36-Shared-Sequence-Policy` 仍是正式最佳；v47 已从“脑暴概念”进入可运行研究基础设施，
但还没有嵌入模型运行时，也没有用户启动入口。

## 本轮真正完成的东西

### 1. 完整序列能力岛基础设施

- 固定了“每任务一次初始 terminal hidden + 完整目标 token 序列”的数据契约。
- 实现 CPU GRU 序列岛训练器，blind 默认锁定。
- 合成自检：154,889 参数、F32 约 0.59 MiB、80 epoch 用时约 0.58 秒；跨模板 validation
  完整序列率和对齐 token 准确率均为 100%。
- 这只证明训练/保存/评估管线可用，不是 ColorLM 真实能力证据。

### 2. 草稿头词表成本被实质削减

并行速度组最初的四未来位完整词表投影约 2.50B FLOPs/步，约为解析基座步的 41.6%，过重。
主线随后对真实 CNOB 做了动态 shortlist 扫描：

- v43 720 个前缀 token：top-16/最多128行也为 720/720 覆盖；
- v44 408 个工具名、参数名/值、结束字段关键 token：
  - top-16/最多128行：406/408，validation 98.04%，拒绝；
  - top-32/最多192行：408/408，validation 100%，允许进入低秩头训练。

下一候选冻结为：原生首 token、rank-64、native top-32、最近上下文96、train-only高频64、最多192行。
这些是已消费 teacher-forced 开发数据，只证明 shortlist 可行，不证明接受长度或端到端加速。

### 3. DALI 式专家分页按门失败

纯离线回放中，动态放置把 GPU 上传从 LRU 的 1961 次降到 519 次，但产生 1347 次 CPU 精确执行；
冷 miss 只下降 2.56%，加预取后总 SSD 读取没有明显优势，未过预声明 5% 门。此路线暂不进 C++。

### 4. 前端短门与单题真实验证

并行前端组建立了 24 题冻结短门，train/validation/blind 各8题且24个模板族不重叠。桌面六个历史
页面在修复 CSS `url(...)`/远程图片依赖漏计后，静态排名为 v17、v7、index、v46、v38、v19；
六份页面仍普遍命中通用三卡片/落地页结构，静态高分不等于视觉审美已经优秀。

主线只消费了 `pf47-train-01` 一条开发题：

- v38 直接 HTML 在 2200 token 和 1800 token 两次都未闭合；
- 第一版自由 Design IR 在 700 token 内也被截断；
- 收紧后的 1065 字节 Design IR 合法且具体；
- IR 条件 HTML 在 3000 token 仍于 9723 字节处截断；一次1400 token续写又重复函数并截断；
- 确定性尾部编译器删除重复函数、修正 drawer/modal 状态、补过滤/键盘/ESC/焦点/状态播报并闭合页面。

冻结静态门：

```text
普通三卡片基线：42.85，模板惩罚17，失败
IR + 确定性编译：80.55，模板惩罚6，全部关键项通过
delta：+37.70
```

真实浏览器检查：桌面状态筛选后10行全部为“警告”，详情抽屉和告警弹窗可开关；375px 下表格隐藏、
50张卡片显示、无横向溢出，控制台无错误。移动卡片文字仍略拥挤，视觉精修未完成。

这个结果只证明“短 Design IR + 结构化编译”方向在一条 train 题上有价值。候选含确定性修复，不能说
纯 v38 或 v47 模型已经获得 80.55 分，也不能推到通用前端能力。

## 下一步的唯一主顺序

1. 用 8 条 train 前端题建立 150–600 字节优先、最长1200字节的闭集 Design Genome IR，并把尾部
   修复扩成直接输出最终 HTML/CSS/JS 的通用确定性编译器，禁止针对单题硬编码。
2. 先由 v38 受 JSON Schema/grammar 约束生成短 IR，测真实端到端墙钟；8题只证明编译器，不训练
   一个自由文本 GRU 后宣称泛化。
3. 只从 train 家族组合/改写至少128条轨迹，用户专有文本走 copy slot，再采 initial hidden 并蒸馏
   pointer/copy 序列岛。
4. 在 8 条 validation 上要求至少6题通过、相对模板中位增益≥12、零关键回归；通过才开一次 blind。
5. 同时训练 rank-64/192行的未来 token 草稿头；teacher-forced 覆盖后必须做自由滚动与拒绝位置
   replay，再测平均接受长度。解析加速下界不足8%就停止，不改 C++。
6. 只有前端/工具序列岛先证明完整任务净增益，才训练 `K=0..4` 递归路由；DALI 分页保持暂停。

## 不允许再做

- 重跑 v24 n-gram；
- 直接拼 Qwen 中层或固定 alpha 扫描；
- 用一颗 K3/GLM 专家切片宣称完整前端能力；
- 用单 token NLL、输出变化或单页静态分宣称模型晋级；
- 在 validation/blind 上扩词表、选 rank 或补规则。
