# 北极星经络架构 v0

日期：2026-08-01
状态：研究契约；不是已晋级模型，也没有新增用户启动入口。

## 目标

北极星不是把另一个普通开源模型换成主干，而是在一个快速常驻主干外建立巨型模型器官库：

- donor 总容量允许达到 300B--2.8T；
- 本地可保存 50--70GB 冷器官和更大的远端 Range 目录；
- 每 token 实际活跃量控制在约 3--5B；
- RX 5700 XT 8GB + 32GB RAM 上守住至少 20 token/s；
- 不做大规模蒸馏、LoRA 或 epoch 训练，只允许解析式重构、闭式坐标校准、量化与激活统计。

这里的“八卦、五行”只是调度拓扑的助记名称，所有晋级仍由隐藏态、NLL、任务结果和实际字节证明。

## 已证伪的朴素方案

### 原样运行巨型 donor

- Kimi K3 原生路径每 token 引用 92 层 × top-16 = 1,472 个专家页，专家载荷约 25.83GB。
- 104B active 即使按 Q4 也约 52GB/token；RX 5700 XT 448GB/s 的纯带宽理论上限只有
  8.62 token/s，还没有计算 attention、KV、同步与量化开销。
- 本机真实随机多 span 读取约 207.39MiB/s；20 token/s 要求 K3 页命中率约 99.958%。

因此“SSD 上放完整 K3，经路由逐层调页”不能达到目标。

### 把一颗专家叫作能力器官

DeepSeek、GLM 和 K3 的单专家都依赖供体原生隐藏态、router、shared expert、norm、残差语义和
上下游层。一颗专家物理上可切，不代表它包含可独立搬运的推理、前端或工具能力。

### 连续编号微块

四颗真实 K3 专家均完成 `48 × 64` 神经元扫描。以完整专家输出为参照：

| 专家/隐藏站 | top-4 激活神谕 cosine | top-8 | top-16 |
|---|---:|---:|---:|
| L28/E41，base L12 | 0.474 | 0.606 | 0.764 |
| L28/E41，base L28 | 0.464 | 0.596 | 0.752 |
| L28/E780，base L12 | 0.493 | 0.617 | 0.764 |
| L65/E539，base L28 | 0.400 | 0.539 | 0.709 |
| L65/E752，base L28 | 0.409 | 0.541 | 0.709 |

真实输出贡献神谕没有明显改善；低秩 `G^T G + U^T U` 解析路由更低。这说明神经元物理编号不是
天然能力经络，不能把相邻 64 个神经元机械地当一颗“微专家”。

## 新的最小单位：原生坐标器官段

一个可进入能力门的器官不再是单 tensor 或单专家，而必须包含：

1. 明确的供体版本、连续层区间和原生 hidden/state ABI；
2. 该区间的 norm、attention/state、router、shared path 与实际命中的 routed experts；
3. 入口和出口成对的激活坐标门；
4. 强制 no-op / donor 的归因路径；
5. 独立 cache、字节、stall 与状态生命周期账本。

单专家继续称为“页”，不再称为“能力胶囊”。

## 八宫能力总线

八宫不是八个固定神经网络，而是八种可独立验收、可为空的能力槽：

| 宫 | 工程能力槽 | 首选证据 |
|---|---|---|
| 乾 | 规划与长程推理 | 计划约束满足、反事实关键 token NLL |
| 坤 | 知识、上下文与记忆 | 闭卷事实、长上下文取证 |
| 震 | 工具选择与动作 | 工具名、参数、结束状态完整轨迹 |
| 巽 | 编程、调试与补丁 | 单测、补丁最小性、跨文件一致性 |
| 坎 | 校验、风险与反例 | 发现错误、拒绝有害候选、回归率 |
| 离 | 视觉、UI 与前端设计 | 截图理解、响应式布局、浏览器动作 |
| 艮 | 停止、边界与状态收束 | 不重复调用、长度控制、状态清理 |
| 兑 | 对话、表达与需求澄清 | 人类偏好、格式遵循、少废话 |

K3 的 0.895GB 视觉塔只可能进入“离宫”的感知侧；它不是 K3 的 HTML/CSS/JS 或网页审美因子。

## 五相仲裁

每次困难片段只经历五个确定动作：

1. **观象**：快主干的浅/中/深三个摘要共同判断困难度，不用关键词分类。
2. **定宫**：选择一个能力槽及一个原生器官段；路由跨 3--4 层保持，隐藏漂移超阈值才重选。
3. **生候选**：器官只提出短候选、结构 IR、补丁或工具动作，不直接无限续写。
4. **相克验证**：快主干或验证宫检查候选；冲突时 no-op，不把 donor 变化强行提交。
5. **归藏**：提交通过的结果，并更新热页、路由段和失败账本；默认回到快主干。

这等价于“候选与验证分离 + 低占空比巨型器官”，不是让几百 B 权重每 token 常开。

## 首颗 300B+ 器官路线

首选供体改为 `DeepSeek-V4-Flash-0731` 的末端连续皮层 L40--L42，理由是：

- 官方 checkpoint 为 304.18B 实计参数、284B 核心口径、13B active；符合 300B 级供体目标；
- 官方 DSpark 本身读取 L40/L41/L42 三处状态，证明这三处是明确的末端多深度接口；
- hidden 4096，矩形激活桥比 K3 的 7168→2048 更小；
- 单 expert+router 身份页仅 13,377,540B，适合先验证 FP4/UE8M0 Range ABI；
- 三层连续段可保留 attention、mHC、router、shared path，而不是再次孤立注入一颗专家。

以上理由只说明它是首个可证伪对象，不预先声称 L40--L42 已包含 Claude/GPT 级能力。

### 必须先取得的原生证据

本地不得用 embedding Procrustes 冒充内部激活桥。下一步应使用免费/临时云算力做一次流式供体前向：

1. 固定少量跨能力 prompt；
2. 逐层流式读取 DeepSeek 权重，在供体原生坐标中运行，记录 L39--L42 hidden、mHC state、
   router top-k 和输出 NLL；
3. 权重只在云端暂存/流过，回传小型激活 CNOB 与精确页 manifest；
4. 与同 prompt 的北极星浅/中/深 hidden 配对；
5. 用 nullspace-anchored 矩形 CCA/Procrustes 做闭式入口/出口门，不反向传播；
6. 只有留出任务上的坐标、强制路径 NLL 与实际生成同时通过，才 Range 提取 L40--L42 热集合。

这一步使用巨型模型真实激活来确定器官入口，不是用小模型训练北极星。

## 速度合同

当前 v38 快主干约 26--29 token/s。以 28 token/s 为参照，要守住 20 token/s，额外慢路径的
平均预算为：

```text
1/20 - 1/28 = 14.29 ms/token
```

因此巨型器官必须按困难片段触发并摊销。若一次器官调用耗时 `C` 毫秒，则长期平均调用率必须
不高于 `14.29 / C`。50 token/s 高于当前快主干，必须靠北极星原生多 token 草稿/无损验证，
不能指望切片本身加速。

## 晋级门

1. `alpha=0` 或 no-op 时不加载器官、不建器官节点，逐 token 回到正式主干。
2. 激活桥必须按整任务留出，显著优于 embedding bridge；不得只报告 train cosine。
3. 连续器官段的强制路径在关键 token NLL 和完整任务上均有净改善，且删除任一任务后方向不翻转。
4. donor 原生 route trace 必须能解释实际下载的 expert 页；禁止猜“前端专家 ID”。
5. 相邻端到端短测不低于 20 token/s，并记录 SSD/RAM/PCIe/VRAM 实际字节和 p95 stall。
6. 一个能力槽通过，不得宣称整体追上 Claude/GPT；八宫分别记账。

- K3：复用已有 6 颗真实页；不继续盲下专家。
- DeepSeek：原生流式 trace 工具未就绪前不下载 3.59GB 整层或 10.86GB DSpark；允许之后按
  header Range 取一个 13.38MB 身份页验证 ABI。
- GLM-5.2：暂缓。40B active、6144 hidden 和 75.5MB BF16 单专家均比 DeepSeek 首样本更重。
