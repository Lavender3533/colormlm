# ColorLM 突破路线

## 结论

ColorLM 要在 1--15 GiB 内真正超过远大于它的闭源模型，不能只依赖更多静态参数。
核心路线是把静态语言模型改造成一个持续运行、稀疏激活、能够形成新状态并反复修正
自身预测的神经系统。最终比较的是同等任务和工具权限下的正确结果、时间与资源，而
不是模型自称什么，也不是挑选几个看起来成功的回答。

当前 `ColorLM-v4-SMoE.gguf` 仍以 Qwen3.5-35B-A3B 的知识张量为主体。已经迁移的
ColorKernel 和递归 FFN 只证明新计算图能够运行，尚未证明智能超过供体。以下路线
专门约束后续工作，防止把架构演示误报为能力突破。

## 从大脑借鉴什么

人脑不能用一个确定的 FLOPS 数字与 GPU 直接比较。约 860 亿神经元、数量级约
`10^14--10^15` 的突触、稀疏脉冲和模拟动力学只是结构估计；关键差异是大脑不会在
每个时刻激活全部连接，也不会把所有经历直接写成永久知识。

ColorLM 对应采用五个部件：

| 生物机制 | ColorLM 部件 | 必须产生的实际收益 |
|---|---|---|
| 稀疏皮层 | SMoE 神经核心 | 15 GiB 内只激活约 3B 参数 |
| 工作记忆 | 请求内 Delta/Kernel 状态 | 固定状态大小处理长序列 |
| 海马系统 | 独立的情景状态库 | 新会话能回忆已确认事实且不拼接原文 |
| 皮层巩固 | 低秩快速权重更新 | 1--30 秒把验证过的经验写入模型状态 |
| 丘脑与全局工作区 | 共享权重潜空间循环 | 难题反复修正同一潜状态，简单题快速退出 |

工作记忆、情景记忆和语义权重必须物理分离。请求结束后自动永久保存全部 recurrent
state 会积累用户问题、错误答案和采样噪声，因此禁止作为“学习”实现。

## 目标计算图

```text
输入 token
   -> 稀疏感知核心（30 x ColorDelta + 10 x ColorKernel）
   -> 全局潜状态 Z
   -> 共享认知循环 C(Z, 工作状态, 语义状态)
   -> 预测误差 E = Z_next - Predict(Z)
   -> 连续置信门 G(E, Z)
   -> 输出头

已确认经历 -> 情景状态 -> 1--30 秒局部巩固 -> 低秩语义状态
```

循环不是生成多份文本再投票，也不是关键词 `if`。同一个神经核心在潜空间中共享
权重，每轮更新唯一状态。退出门必须是模型张量计算的一部分；在退出门完成校准前，
使用固定两轮作为可重复基线。

## 三道硬门槛

任何新机制只在同时提供对照数据时进入主模型：

1. **能力门**：预先冻结的小型盲测集中，正确率或可执行任务成功率高于改动前；
2. **污染门**：写入新事实后可以跨进程回忆，至少 100 个无关问题的输出不发生系统性偏移；
3. **效率门**：RX 5700 XT 上记录首 token、生成速度、峰值显存，收益不是来自少生成内容。

单纯更改元数据、自我介绍、系统提示词、检索拼接、关键词路由、候选答案投票和仅能
证明程序未崩溃的测试，都不算能力进展。

## 超越 GPT-5.5 的验收定义

“真正超过”必须覆盖实际工作而不是单一跑分。双方使用相同题目、上下文、时间限制
和工具权限，隐藏模型名称，至少覆盖：

- 软件工程：修改真实仓库并通过隐藏测试；
- 推理：可自动判分的数学、逻辑和约束规划；
- 长任务：跨多轮保持要求、发现错误并完成修复；
- 新知识：现场教授后跨进程准确使用，且不依赖重新注入原文；
- 效率：总耗时、首 token、显存、内存和磁盘占用。

目标通过条件是 ColorLM 的任务成功率总体领先，同时模型文件不超过 15 GiB。模型
身份回答和主观“看起来更聪明”不进入计分。

## 实施顺序

1. 用满可用 GPU：热专家层常驻显存，启动时完成 Vulkan 预热；
2. 将请求内状态与可持久化情景状态分离，先完成无污染的保存/恢复；
3. 接入模型内连续写入门，只允许已验证轨迹进入巩固队列；
4. 实现共享潜状态循环和连续退出门，用短时校准学习尺度与阈值；
5. 扩展 ColorKernel 层数，每次只保留通过三道门槛的版本；
6. 最后进行与目标模型的同权盲测，未通过的任务直接成为下一轮训练信号。

## 已否决路径

`2026-07-25` 对“把请求结束时的 ColorKernel 工作状态直接 EMA 到慢状态”做了最小
行为验证。2 MiB 状态能够写入、改变文件哈希并跨进程恢复，但对从未见过的随机事实
`K7-1942`，在 `rate=1.0`、慢状态读取强度 `1.0` 时仍无法跨会话回答。说明普通
推理状态不等于受监督的问答关联。该读取路径默认关闭，也不作为用户功能；下一实现
必须用 next-token 预测误差直接更新低秩参数，并在进入主模型前先通过随机事实回忆与
污染门槛。

`2026-07-26` 又冻结三道此前未用于调参的计数、贝叶斯和真假话题，正确答案分别为
`266`、`1/6`、`B`。以下增加计算的方法均未越过能力门，因此不进入默认模型：

| 方法 | 正确数 | 结果与代价 |
|---|---:|---|
| 当前 ColorLM 快速图 | 1/3 | `266` 正确，其余错误 |
| 关闭 ColorKernel/塑性头的供体图 | 1/3 | 没有证明新图超过或弱于供体 |
| 192-token 内部推理 | 1/3 | 约 14--18 秒/题，仍答错后两题 |
| 草稿再审查两轮 | 0/3 | 把正确的 `266` 改成 `267`，约 20 秒/题 |
| top-16 专家（供体为 top-8） | 1/3 | 生成一度降到约 8--9 token/s，无能力增益 |
| 模型编译受限表达式再执行 | 未通过 | 整除题正确，但把贝叶斯联合概率编译错，执行只会精确放大语义错误 |

这组结果说明更多 token、更多未训练专家和宿主审查外壳都不能替代新的推理连接。
客户端恢复为快速稳定模式；失败机制不向用户宣称为“高智能”。

## ColorPlasticity 首次通过行为门（2026-07-26）

ColorLM v4 已接入一组始终参与 GPU logits 的连续低秩参数：

```text
h(2048) -> 固定随机投影 A(256 x 2048) -> L2 归一化 z
logits = 冻结主干 logits + B(248320 x 256) @ z
```

`A` 为 F32，`B` 为 F16，总计 `129,237,032` 字节（文件头加约 `123.25 MiB`
张量）。它们被分配在 Vulkan recurrent buffer 中，不经过文本检索、关键词路由或
候选答案选择。短时学习从模型自身的因果最终隐藏状态取得神经键，用带竞争抑制的
局部预测误差更新 `B`；答案结束 token 也作为目标，以防止最后一个 token 形成循环
吸引子。

冻结随机事实 `瑟蓝协议的校验码是 K7-1942` 后的必要行为证据：

| 检查 | 结果 |
|---|---|
| 未学习基线 | 回答该协议不存在，不知道校验码 |
| 快速学习 | 8 个预测目标，`1.783 s` |
| 清空会话后 | 精确输出 `K7-1942` 并以 `stop` 结束 |
| 结束并重启服务 | 仍精确输出 `K7-1942`，约 `17.31 token/s` |
| 无关问题 `9+8` | 正确输出 `17` |
| 清零 | `B_nonzero = 0`，回答恢复为 `无校验码` |

这证明“可验证经验 -> 短时连续参数更新 -> GPU 生成 -> 跨进程保持”链路已经真正
闭环。它解决的是新知识写入机制，不代表通用推理能力已经超过目标模型。

随后加入 `256 x 256` 的逆相关神经统计量（约 `256 KiB`）。它不保存问题、答案或
token 目标，只记录已经占用的潜空间方向；后续误差通过递归最小二乘增益优先写入
新方向，并对既有活跃输出形成竞争约束。顺序写入两条具有重叠数字和终止 token 的
合成知识后，结果如下：

| 顺序 | 写入 | 耗时 | 最终回忆 |
|---|---|---:|---|
| 1 | `K7-1942` | `2.110 s` | `K7-1942` |
| 2 | `VX-8031` | `1.946 s` | `VX-8031`，同时旧知识仍为 `K7-1942` |

这只是抗遗忘机制的最小行为门，容量和长期干扰仍需要逐级扩大验证。下一实现是把
同一隐藏状态送入共享认知单元反复修正，并用预测误差形成连续退出信号，实现潜空间
自适应计算。

## 评测纪律、温度混淆与巩固回路（2026-07-26，第二批）

### n=3 对照无统计效力，已建冻结能力门

此前否决表全部建立在 3 道冻结题上。n=3 时 1/3 的 95% Wilson 区间是
[6%, 79%]，因此 1/3、0/3、1/3 之间不可区分；"top-16 无增益""192-token
推演无增益"这类结论只有方向性参考价值，不是证据。能力门现已实现：

- `evalgate/gen_frozen.py`：60 题 6 家族，参数随机生成、答案由代码计算，
  种子 20260726，ground truth 不依赖任何模型；`frozen_v1.json` 冻结，
  禁止用于训练、调参和提示词迭代；
- `evalgate/run_eval.py`：fast/deep 对 8092 自动评测，默认贪心解码，
  按「答案:X」末行判分，输出 Wilson 区间；`compare` 子命令做配对
  McNemar 精确检验。今后任何"能力变化"主张必须先过这道门。

### 温度混淆：此前 fast/deep 对照全部失控

fast 模式一直用 temperature 0.35、deep 用 0.1，两模式对照从未控制解码
变量。贪心解码（temperature 0）下的写入前基线实测：

| 题 | 记录中 fast(0.35) | fast(贪心) |
|---|---|---|
| 年龄题（答案 11 类） | 曾输出错误 13 | 正确 |
| CRT 余数 93 | 未测 | 正确 |
| CRT 余数 38 | 未测 | 正确 |

"deep 可复现修正年龄题"这一收益中不可忽视的部分其实是采样噪声，
不是推演能力差。客户端 fast/deep 已统一改为贪心解码；此前否决表
（以及 1/3 频发的冻结三题结果）在解读时都要叠加这层混淆。

### 已验证答案巩固回路（路线图第 3 步，已实现，等待合适标本）

`consolidate_v4.py` 实现自主巩固闭环：deep 自解 → 写入门（判分核对
外部验证答案 + finish_reason=stop，失败轨迹拒绝写入）→ 模型自己的
作答文本经 ColorPlasticity 巩固 → fast 复答验证继承，附写入前/后的
污染与同族泛化探针。运行前经三路对抗审查修复 2 个致命缺陷：
`/embeddings` 受服务 n_ubatch=512 硬上限（巩固前用 /tokenize 预检，
超限中止；解除上限需 `--ubatch-size 2048` 重启服务，8GB 显存下有
OOM 风险，是否解除由人决定），以及全程无异常保护会丢失唯一一次
运行的证据（已改为逐阶段落盘）。

两次实际运行均在基线关卡正确中止（exit 3）：贪心 fast 直接解出了
年龄与 CRT 两族，巩固的前提"fast 失败且 deep 成功"不成立。结论：

1. 回路机制就绪且闸门纪律有效，但"fast 败、deep 胜"的标本比 n=3
   数据暗示的稀少；找它的系统办法是跑一次 evalgate 双臂对照，
   看 McNemar 不一致格里 deep 独对的题；
2. 双模式都失败的家族（贝叶斯、真假话）自解巩固原理上无法启动，
   这些必须走外部真值 `/learn`（已验证）或训练路线；
3. reasoning_format=deepseek 下思考流不进 content，当前被巩固的是
   答案行而非完整推理轨迹；完整轨迹巩固要先解除 512 上限。

## 快速模式与内部推演（2026-07-26）

已实现共享末层权重的图内潜状态循环，但必要对照中，两轮循环与关闭循环都在同一道
年龄约束题上输出错误答案 `13`，没有形成能力增益，因此循环代码保留为后续可训练
机制，默认轮数设为 `0`，不把未生效的架构实验交给用户。

同一神经核心的请求级内部推理通道则产生了可复现收益：快速模式直接输出 `13`；开启
thinking 后模型列出方程并得到 `11`。加入预算耗尽收束消息后，内部预算从 384 token
逐步降到 64 token 仍能输出 `11`，一次请求总计生成 79 token。客户端因此提供显式
`/fast` 与 `/deep` 两种模式，不使用关键词分类器自动猜测任务难度，也不生成多个答案
投票。
