# GLM-4.7-Flash 人工验收

这不是通用排行榜，只验证模型是否适合 ColorLM 的真实目标。

## 运行条件

- 模型：`GLM-4.7-Flash-Q5_K_M.gguf`
- 服务端：`fast16/start_glm47_bare.py`
- 不加载 ColorPlasticity、知识库、候选投票或 ColorDream。
- 工具调用场景建议采样：`temperature=0.7`、`top_p=1.0`、`min_p=0.01`、`repeat_penalty=1.0`。

## 任务 A：自然对话

用真实需求连续交流，不使用“你是一个专业助手”类风格提示词。

记录：

- 是否准确理解意图。
- 是否重复、套话或自我身份混乱。
- 是否能在多轮后保持上下文。

## 任务 B：真实网页

让模型在一个空目录中完成一个真实可用网页，不提供现成代码。

成功条件：

- 项目可安装并启动。
- 浏览器控制台无错误。
- 交互可实际使用，移动端布局不破裂。
- 记录人工修改次数与虚构 API 数量。

## 任务 C：Minecraft Mod

开始前必须固定：

- Minecraft 版本：待选定。
- Loader：Fabric 或 Forge，待选定。
- Java 版本：待选定。
- Mappings/API 版本：待选定。

成功条件：

- Gradle 构建通过。
- 游戏可启动且 Mod 被加载。
- 目标功能在游戏中真实出现。
- Java、资源 JSON、Mod ID 和注册信息保持一致。
- 记录从空目录到首次成功运行需要的轮数。

## 判定

- 能完成 B 和 C：可作为 ColorLM 新主线基座。
- 只能完成 B：可作为普通本地助手，不足以承担目标。
- 不能稳定完成 B：不继续在该供体上研发。
- 后续 ColorLM 版本必须在相同任务上减少人工修改次数，否则不算能力进步。
