# ColorDream：夜间自举巩固

一句话：模型每晚自己出题、自己重解、机器验证、把验证过的解写成永久参数，
天亮时比昨天强一点,且有冻结门证明没有变笨。目标是把这条曲线一直推到
在同题同工具盲测上反超 Opus。

## 为什么这条路在结构上能赢

| 资源 | Opus (API) | ColorLM (本机) |
|---|---|---|
| 每次回答的算力 | 被 API 经济学限死 | 只受耐心限制 |
| 夜间闲置算力 | 不属于用户 | 每晚 8-10 小时,免费,×365 |
| 跨会话学习 | 无状态,永远冷启动 | 塑性写入已闭环(K7-1942) |
| 在用户分布上的积累 | 零 | 每一次验证通过都是永久资产 |

反超不靠在对方主场(零样本知识广度)硬拼,靠把上面右列的结构优势
复利化:可验证域先赢,程序性权重外溢到邻近域,领土逐年扩大。

## 与大脑的对应(补全架构表缺的一行)

| 生物机制 | ColorLM 部件 | 必须产生的实际收益 |
|---|---|---|
| 睡眠回放与巩固 | ColorDream 夜间循环 | 白天做不出的题,睡一晚后 fast 直接做对 |

## 循环(每晚)

```text
1 出题   在能力前沿自动生成带机器判据的题
         难度定标:fast 与 deep 答案分歧率(不确定性信号,不是关键词规则)
         题必须可机器验证:代码可执行 / 数值可复算 / 约束可枚举
2 重解   deep + 大预算逐题求解(夜里不心疼 token)
3 验证   只认硬判据(执行/检验器复算)。禁止候选投票当真值
4 巩固   验证通过的轨迹 -> 写入门 -> 塑性参数(consolidate 链路已建成)
5 免疫   收盘自动跑冻结门子集 + 污染探针
         任何回退 -> 当晚写入整体回滚(塑性文件每晚开盘快照)
```

第 3 步与"推理时投票"的区别必须说清:投票被本项目永久禁止作为能力来源;
这里的验证器不进推理路径,只筛选训练信号,真值来自执行结果而非多数意见。

## 三个版本

- **v0(现有机器,零新架构)**:出题器扩展 evalgate 生成族(绝不触碰冻结集),
  巩固走现有 logit-bias 塑性头。预期只能积累"题-解"关联,先把循环、
  快照、回滚、免疫协议全部跑通,并测出塑性头容量曲线(多少条开始互相干扰)。
- **v1(算法核心,世界上没有的部分)**:实现规范里设计但未实现的宏单元隐层
  快速权重 `F = A @ B`,用局部预测误差在线把验证轨迹蒸馏成**程序性**权重
  (不做全网反传,fork 我们自己控制计算图)。logit 偏置只能记答案;隐层
  快速权重才能记"怎么解"。这是从记忆走向能力的那一步,也是最大的研究风险。
- **v2(慢波睡眠)**:快速权重积累到阈值后,夜间蒸馏进 LoRA/主干,腾空
  快速容量。本机训不动就攒批上云,白天照常服务。

## 反超 Opus 的验收阶梯

1. 夜梦零回退:连续 7 晚,冻结门不降、污染探针不炸;
2. 曲线向上:冻结门(60 题,种子 20260726)月度正确率单调上升;
3. 逐族反超:按"超越 GPT-5.5 验收定义"(同题、同上下文、同工具、盲名),
   把对手换成 Opus,先在夜梦最久的可验证家族打赢第一场;
4. 领土扩张:反超家族数逐季增加,直至总体任务成功率领先。

模型自称什么、看起来多聪明,永远不进计分。

## 明确不做

- 不做 t/s 竞赛:速度只在"每晚能做多少梦"里间接有用(MTP/rebase 押后);
- 不做推理时投票、检索拼接、关键词外壳(全家已否决);
- 不碰冻结题库:出题器与 frozen_v1.json 的参数空间硬隔离,发现碰撞即弃题;
- 不在证据前宣称:每一级阶梯的报告落盘,负结果照写。
